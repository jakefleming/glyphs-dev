# Rigormortise for Glyphs

Rigormortise updates spacing and kerning as you draw. Open
**Edit → Rigormortise…** and enable it for the selected master.

The [Rigormortise guide](https://github.com/jakefleming/glyphs-dev/blob/main/Plugins/Rigormortise/README.md)
covers installation, controls, manual adjustments, similar-pair rules and
restoring your starting spacing.

This directory contains the plugin's Python adapter and Swift worker. Build
scripts and tests are in `Plugins/Rigormortise/` in the repository.
